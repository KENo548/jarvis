# JARVIS Scaffold

This folder is the beginner-friendly scaffold referenced by the local-only setup
guide.

Contents:

- `agents/` - short role notes and local-first agent reminders
- `mcp-servers/` - MCP server stubs and registry notes
- `memory/` - local memory setup notes and approval queue references
- `tools/` - helper scripts and local runner entrypoints
- `workflows/` - orchestration notes and graph placeholders

Use the root project folders for the actual runtime implementation. This folder
exists as a clean, easy-to-follow starting point for the Phase 1 checklist.
