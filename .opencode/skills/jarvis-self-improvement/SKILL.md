# Self-Improvement

## What I do

- Pattern recognition from past work
- Retrospective analysis
- Continuous improvement tracking
- Knowledge capture
- Anti-pattern documentation

## When to use me

Use this skill for retrospective, pattern learning, knowledge capture, or improvement tracking.

## Patterns

### Retrospective Template
```markdown
## What went well
- [Success 1]
- [Success 2]

## What could improve
- [Improvement 1]
- [Improvement 2]

## Action items
- [ ] [Action 1]
- [ ] [Action 2]
```

### Pattern Capture
```markdown
## Pattern: [Name]
- **Context**: When this applies
- **Solution**: What works
- **Anti-pattern**: What doesn't work
- **Evidence**: Where this was validated
```

### Learning Log
```markdown
## Learning: [Date]
- **What**: What was learned
- **Why**: Why it matters
- **How**: How to apply it
```

## Anti-patterns

- Don't blame — analyze
- Don't repeat mistakes without documenting
- Don't skip follow-through on action items
